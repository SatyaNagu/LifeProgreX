# LifeProgreX

**Your Personal Growth Companion**

LifeProgreX is a cutting-edge Flutter application designed for Clark University's Capstone project. It helps users track their habits, health data, and personal milestones through a visually stunning dashboard and AI-powered insights.

## 🌟 Key Features

- **AI Coach (Max):** Personalized feedback and motivation using Gemini AI.
- **Health Integration:** Sync with Apple Health and Google Fit.
- **Dynamic Analytics:** Beautiful, interactive charts to visualize your progress.
- **Achievements System:** Gamified experience to keep you motivated.

## 🛠 Getting Started

### Prerequisites
- Flutter SDK (latest version)
- Firebase Account
- Google Generative AI API Key

### Installation
1. Clone the repository.
2. Run `flutter pub get`.
3. Configure your `google-services.json` (Android) and `GoogleService-Info.plist` (iOS).
4. Run the app: `flutter run`.
