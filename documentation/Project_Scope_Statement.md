## 1. Project Objective
To design, develop, and deploy a mobile application that aggregates health data and habit progress into an AI-powered "Life Resume," providing users with actionable insights for personal growth.

## 2. Product Scope Description
The application features a dark-themed, glassmorphic UI with dynamic charts (Analytics), a chat-based AI interface (Max), and a reward system for habit consistency.

## 3. Project Deliverables
- **Mobile Application:** Built with Flutter for iOS and Android.
- **Backend Infrastructure:** Firebase-based NoSQL database and authentication.
- **Project Documentation:** Project Charter, Scope Statement, and Developer Guide.
- **Final Report:** Technical summary and presentation materials.

## 4. Product Acceptance Criteria
- Successful integration of Google Generative AI (Gemini) responding to user logs.
- Real-time synchronization with Apple Health data (Steps, Sleep, Workouts).
- Achievement system triggers correctly upon completion of set milestones.

## 5. Project Boundaries
- **Inclusions:** Full-stack development, AI prompt engineering, data visualization.
- **Exclusions:** Multi-language support (English only for V1), internal payment gateway, third-party plugin marketplace.

## 6. Project Constraints
- **Schedule:** Must be completed by the Capstone deadline.
- **Technology:** Must utilize the approved Flutter/Firebase stack.
